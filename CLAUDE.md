# MGIMO Hub: личный кабинет студента (хакатон «Цифровой деканат будущего»)

Инструкция для ИИ-агентов (Claude Code и любых других), которые работают с этим репозиторием.
Прочитай целиком перед первой правкой. Подробности — в `docs/`.

@AGENTS.md

## Что это
Прототип личного кабинета студента MGIMO Hub для хакатона. ИИ-ассистент внутри называется «Атташе». Все люди, оценки и документы вымышлены (в интерфейсе об этом не пишем). Официальный логотип МГИМО не используем, у продукта свой знак.

- Продукт и сценарии: `docs/PRD.md`
- Дизайн-система: `docs/DESIGN.md`
- Безопасность и модель угроз: `docs/SECURITY.md`
- Журнал процесса (для отчёта жюри): `docs/PROCESS.md` — **дописывай туда каждое значимое решение и каждую ошибку ИИ, которую пришлось исправлять**
- Исследования: `docs/research/`

## Стек
- Next.js 16 (App Router, TypeScript, Turbopack). **Это не тот Next.js, что в обучающих данных** — сверяйся с `node_modules/next/dist/docs/`.
  - `cacheComponents` выключен сознательно (кабинет полностью персональный) — классический динамический рендеринг + `loading.tsx`.
  - `middleware.ts` → `src/proxy.ts`, функция `proxy` (Node runtime).
  - `params`, `searchParams`, `cookies()`, `headers()` — асинхронные (`await`).
- Tailwind CSS v4 (токены в `src/app/globals.css`, `@theme`), свои UI-компоненты в `src/components/ui`.
- PostgreSQL 17 + Drizzle ORM (`src/db/schema.ts`), миграции в `drizzle/`.
- Пароли: argon2id (`@node-rs/argon2`). Сессии: случайный токен в httpOnly-cookie, в БД хранится только SHA-256 токена.
- ИИ: DeepSeek (OpenAI-совместимый API), вызывается **только с сервера** (`src/lib/assistant`). Без ключа — офлайн-режим.

## Команды
```bash
docker compose up -d db     # Postgres на localhost:5433
npm run db:migrate          # применить миграции
npm run db:seed             # заполнить вымышленными данными
npm run db:reset            # снести и пересоздать всё
npm run dev                 # http://localhost:3000
npm run typecheck && npm run lint
npm run test:security       # проверка изоляции данных (нужен запущенный dev-сервер)
```
После изменения `schema.ts`: `npm run db:generate` → `npm run db:migrate`.

## Структура
```
src/app/(auth)/login        вход

src/app/api/...             route handlers (ассистент, календарь .ics, счётчик уведомлений)

src/lib/data                ВСЕ запросы к БД для страниц (Data Access Layer)

src/db                      схема, подключение, миграции, сид
```

## Инварианты безопасности (нарушать нельзя)
1. **Данные студента берутся только по `student.id` из сессии.** Никогда не принимай `studentId` из URL, формы или тела запроса.
   Любой поиск по id из URL — `where(and(eq(table.id, id), eq(table.studentId, me.id)))`, а при промахе — `notFound()` (404, а не 403: не подтверждаем существование).
2. Все запросы к БД — в `src/lib/data/*` и начинаются с `requireStudent()` / `requireStaff()`. Страницы и экшены не ходят в БД напрямую.
3. Каждый Server Action и Route Handler сам заново проверяет сессию и роль. Проверка в UI — не защита.
4. Сотрудник видит только заявки своего факультета (`staff.facultyId`; `null` = единый студенческий офис, все факультеты).
5. Пароли — только argon2id-хэш. Токен сессии в БД — только SHA-256. Секреты — только в env, никогда в клиентском коде и не с префиксом `NEXT_PUBLIC_`.
6. ИИ-ассистент получает контекст только текущего студента; его «действия» — это подготовленные черновики/ссылки, которые студент подтверждает сам.
7. Никаких реальных персональных данных. Только вымышленные ФИО, номера, оценки.

## Правила интерфейса (решения автора, не нарушать)
- Строгий стиль v2 (см. `docs/DESIGN.md`): нейтральные серые, один акцент `#2F54EB`, без градиентов, теней, засечек и иконок в плашках.
- Без длинных тире и стрелок в текстах интерфейса, демо-данных и ответах ассистента.
- Не писать в интерфейсе «концепт», «неофициальный», «данные вымышлены». Исключение: водяной знак «образец» на справках.

## Стиль кода
- TypeScript strict, без `any`. Валидация входных данных — zod.
- Серверные модули начинаются с `import "server-only"`.
- Тексты интерфейса — на русском, обращение на «вы», коротко и по-человечески (см. `docs/DESIGN.md#тон`).
- Время всегда показывай по Москве через `src/lib/time.ts`, не через `toLocaleString()` без таймзоны.
- Каждому экрану нужны: состояние загрузки (скелетон), пустое состояние, состояние ошибки.
- Проверяй вёрстку на ширине 360 px.
