# Промпт субагента: исследование реалий МГИМО

Агент: Claude Code subagent (general-purpose, модель Sonnet), запуск в фоне параллельно с разработкой.
Результат: `docs/research/mgimo-facts.md`.

---

Ты — исследователь для хакатона «Цифровой деканат будущего». Мы делаем концепт-прототип личного кабинета студента МГИМО (неофициальный, все данные студентов вымышленные). Пользователь не учится в МГИМО, поэтому реалии университета нужно собрать из ОТКРЫТЫХ источников (mgimo.ru, Википедия, публичные положения, новости).

Собери факты и запиши их в файл docs/research/mgimo-facts.md. Больше никакие файлы проекта не трогай.

Что нужно найти (по каждому пункту — коротко, со ссылками на источник; если не уверен — пометь «[не подтверждено]»):
1. Список факультетов и институтов МГИМО (бакалавриат) с официальными названиями и сокращениями — актуальные на 2025–2026. Есть ли кампус в Одинцово.
2. Примеры направлений подготовки и профилей бакалавриата по 4–5 крупнейшим факультетам (код, название, профиль).
3. Иностранные языки: сколько языков, как устроено изучение (первый/второй язык, языковые группы), самые массовые.
4. Система оценивания: балльно-рейтинговая система (шкала, перевод баллов в оценки, семестр/экзамен), зачёты/экзамены, пересдачи, сроки сессий.
5. Время пар, учебная неделя, адрес основного корпуса и нумерация аудиторий.
6. Стипендии: виды и условия.
7. Какие справки и заявления оформляет деканат, есть ли онлайн-заказ, сроки.
8. Существующие цифровые сервисы МГИМО (ЛК, LMS, расписание) и формат расписания. НЕ парси расписание.
9. Особенности студенческой жизни: обмены, практики (в т.ч. МИД), двойные дипломы, языковые сертификаты.
10. Цвета, ассоциирующиеся с МГИМО (без копирования логотипа).

Ограничения: только публичные источники; НЕ собирай ФИО реальных сотрудников, преподавателей и студентов; по-русски, до ~250 строк; в начале — блок «Главное для прототипа» на 8–12 пунктов; в конце — список источников.
