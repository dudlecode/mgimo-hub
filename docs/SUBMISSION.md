## 3. Чек-лист сдачи (делает человек)

Приём работ с 8 ноября 19:00 МСК, прототип должен работать до 28 ноября.

1. **Хостинг.** Временный сервер уже работает: https://34-88-153-35.sslip.io (Google Cloud). Если с российского интернета он не открывается, нужен российский сервер с Docker (Timeweb Cloud, Selectel, Yandex Cloud, VK Cloud, Amvera): `cp .env.example .env`, затем `docker compose --profile prod up -d --build`.
2. **Окружение на сервере.** Сильный `POSTGRES_PASSWORD` (не значение по умолчанию), `DEMO_MODE=true`, `COOKIE_SECURE=true`, `APP_URL=https://<домен>` (для ссылок в QR).
3. **Домен и HTTPS.** Задать `DOMAIN` (свой домен или `IP.sslip.io`) и запустить `docker compose -f docker-compose.yml -f docker-compose.https.yml --profile prod up -d --build`: Caddy сам получит сертификат. Либо свой прокси на порт 3000.
4. **Ключ ИИ.** `AWS_BEARER_TOKEN_BEDROCK` (или `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY`) либо `AI_PROVIDER=deepseek` и `DEEPSEEK_API_KEY`. На сервере выполнить `npm run ai:check` (или `docker compose exec app ...`): доступен ли Bedrock us-east-1 с российского IP. Если нет, переключиться на прямой DeepSeek. Без ключа Атташе работает в офлайн-режиме.
5. **VAPID для push.** `npx web-push generate-vapid-keys`, задать `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (mailto). Без них push выключен, остальное работает.
6. **Пометка «прототип для конкурса».** Решение автора: в интерфейс строку не добавляем. Что это работа для конкурса, сказано в README, в описании процесса и при сдаче; на справках и квитанциях водяной знак «образец», страницы закрыты от поисковиков (`noindex`), логотипа МГИМО нет.
7. **Проверка с телефона.** С мобильного интернета войти всеми 5 аккаунтами, пройти главный путь: расписание, оценки, заявка, статус.
8. **Свежие данные.** Перед показом и раз в несколько дней `SEED_ON_START=always` или `docker compose exec app node scripts/seed.js`: даты строятся от текущего дня.
9. **Репозиторий.** `git init`, проверить, что `.env`, `.next`, `test-results` не попадают в коммит, поиск по `AKIA`, `ABSK`, `sk-`, `VAPID_PRIVATE` перед пушем. GitHub или GitVerse с доступом для жюри, либо архив на Яндекс Диске.
10. **Описание процесса.** Готово: `docs/MGIMO-Hub-process.pdf` (19 страниц, пересборка `npm run report`). Загрузить на Яндекс Диск или Google Диск с доступом по ссылке.
11. **Видео.** Готово: `video/out/mgimo-hub-demo.mp4` (3:04). Загрузить на Яндекс Диск, VK Видео, RuTube или YouTube с доступом по ссылке. Сценарий ниже остаётся на случай живой записи с голосом.
12. **Отправка.** В блоке «Моя работа»: ссылка на прототип и аккаунты (таблица из README) в комментарии, ссылка на код, ссылка на описание, ссылка на видео.

## 4. Известные мелочи

- У детальных страниц (заявка, дисциплина, карточка студента) нет скелетона загрузки: это плата за честный 404 на чужой id.
- В английском интерфейсе переведены новости деканата и все личные уведомления, имена людей показаны латиницей. Свободный текст сотрудника (сообщение, причина отказа) остаётся как написан, официальные бланки и квитанции на русском намеренно.
- Кнопка «Включить» для push не даёт отклика, если просто закрыть запрос разрешения браузера.
- Экраны ошибки в кабинете сотрудника переведены с `reset` на `retry` (10 ноября): кнопка «Повторить» теперь заново запрашивает данные.
