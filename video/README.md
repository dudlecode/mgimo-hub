# Ролик MGIMO Hub

Ролик для жюри (3:04, 1920x1080, 30 кадров/с): каждая глава начинается с карточки «Было / Стало» о боли студента, живое демо идёт доказательством. Собирается кодом в [Remotion](https://www.remotion.dev): все кадры кабинета сняты с живого прототипа, а графика, титры и наезды камеры описаны в React-компонентах.

## Как устроено

1. **Запись.** `record/record.mjs` запускает Chrome через Playwright и проходит по кабинету как человек: плавный курсор, клики, набор текста, перетаскивание ползунка. Кадры снимаются через CDP screencast в 2560x1600 и склеиваются ffmpeg в `public/footage/*.mp4`. Рядом пишется JSON с метками: когда что показано и где на экране нужный элемент.
2. **Монтаж.** `src/scenes.tsx` описывает 17 сцен. Длины сцен, наезды камеры, синие обводки карточек и кнопок и плашки с пояснениями рядом с ними считаются из меток, поэтому после новой записи ролик пересобирается сам.
3. **Рендер.** `npm run render` собирает `out/mgimo-hub-demo.mp4`.

## Пересобрать

Нужны запущенный кабинет со свежими демо-данными, Google Chrome и ffmpeg.

```bash
npm install
```

```bash
npm run record          # из папки video; сервер по умолчанию http://127.0.0.1:3100 (переменная BASE)
```

```bash
npm run studio          # предпросмотр в браузере
```

```bash
npm run render
```

Чтобы на «Сегодня» была идущая пара с таймером, перед записью можно применить `record/now-lesson.sql` (переносит сегодняшнюю 3-ю пару Анны на 6-ю, 17:55-19:25). После записи базу пересоздайте: `npm run db:reset` в корне проекта.
