# Ролик MGIMO Hub

Ролик для жюри (около 3 минут, 1920x1080, 30 кадров/с). Каждая глава начинается с титра во весь кадр: как было (зачёркнуто) и как стало. Дальше идёт живое демо как доказательство. Собирается кодом в [Remotion](https://www.remotion.dev): все кадры кабинета сняты с живого прототипа, а сцена, титры, плашки и движение камеры описаны в React-компонентах.

Оформление: светлая сцена, кабинет в светлой теме в крупном окне, которое уходит за нижний край кадра, заголовок главы по центру сверху, синие плашки с пояснениями рядом с выделенным блоком.

## Как устроено

1. **Запись.** `record/record.mjs` запускает Chrome через Playwright и проходит по кабинету как человек: плавный курсор, клики, набор текста. Кадры снимаются через CDP screencast в 2560x1600 и склеиваются ffmpeg в `public/footage/*.mp4`. Рядом пишется JSON с метками: когда что показано и где на экране нужный элемент.
2. **Монтаж.** `src/scenes.tsx` описывает 17 сцен. Длины сцен, наезды камеры, обводки и плашки считаются из меток, поэтому после новой записи ролик пересобирается сам. Разные планы склеиваются через белое (старый уходит, новый проявляется), а не наплывом: на светлом интерфейсе наложение двух кадров двоится.
3. **Проверка.** `npm run check:camera` считает скорость камеры по каждому кадру демо-сцен и ловит рывки. `npm run stills -- 150 900 1950` рендерит пробные кадры по номерам в `out/stills`, не дожидаясь полного рендера.
4. **Рендер.** `npm run render` собирает `out/mgimo-hub-demo.mp4`.

## Пересобрать

Нужны запущенный кабинет со свежими демо-данными, Google Chrome и ffmpeg.

```bash
npm install
```

```bash
THEME=light npm run record     # из папки video; сервер по умолчанию http://127.0.0.1:3100 (переменная BASE)
```

```bash
npm run shots                  # светлые снимки 20 экранов для «стены» в финале
```

```bash
npm run studio                 # предпросмотр в браузере
```

```bash
npm run render
```

### Запись в любое время суток

В кадре должен быть учебный день: на «Сегодня» идёт пара с таймером. Если запись идёт вечером, часы сдвигаются в трёх местах на одну и ту же величину `TIME_SHIFT_MS` (миллисекунды, отрицательные для сдвига назад):

1. **Сервер и сид.** `NODE_OPTIONS="--require $PWD/record/shift-time.cjs" TIME_SHIFT_MS=...` перед `npm run db:reset` и перед запуском сервера.
2. **Браузер записи.** Та же переменная `TIME_SHIFT_MS` у `npm run record` и `npm run shots`: карточка «Сейчас идёт» после загрузки считает время по часам браузера.
3. **База.** `record/prep.sql` меняет у столбцов значение по умолчанию `now()` на `now() + сдвиг`, иначе заявка в кадре будет «подана в 21:12» при паре в 14:35:

```bash
docker compose exec -T db psql -U attache -d attache -v shift=$TIME_SHIFT_MS < video/record/prep.sql
```

Тот же файл убирает у Анны старую справку для посольства из демо-данных: в ролике она заказывает такую же через Атташе, и ассистент иначе честно отвечает «у вас уже есть одна».

После записи базу нужно пересоздать уже без сдвига: `npm run db:reset` в корне проекта. Миграции вернут обычные значения по умолчанию.
